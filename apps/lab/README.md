# SC Item Render

Renders Star Citizen inventory items the way the game does, from the local install

Tauri 2 · SvelteKit (SPA) · Svelte 5 · Tailwind v4 · shadcn-svelte.
Scaffolded from [VeeLume/template-tauri](https://github.com/VeeLume/template-tauri).

## Setup

```sh
pnpm install
pnpm tauri dev
```

The icons in `src-tauri/icons/` are placeholders — replace them with
`pnpm tauri icon path/to/source.png` before anything ships.

Before the first release, generate an updater keypair and paste the public half
into `src-tauri/tauri.conf.json` (`plugins.updater.pubkey`), then point
`endpoints` at wherever `latest.json` will live:

```sh
pnpm tauri signer generate -w ~/.tauri/sc-item-render.key
```

Keep the private key out of the repo — `.gitignore` already refuses `*.key`.

## Layout

```
src/                    SvelteKit SPA
  app.css               token structure: density scale, @theme mapping, base layer
  theme.css             the colours — yours, copier never touches this
  lib/
    bindings.ts         GENERATED by tauri-specta on every debug build
    breakpoint.svelte.ts   window-size classes (600 / 840 / 1200 / 1600)
    nav.svelte.ts       navigation model    stores/             appearance (theme + density), settings, updater
    components/         NavRail, BottomNav, UpdateBanner
crates/                 library crates — see crates/README.md
src-tauri/              the Rust shell
  src/settings.rs       one JSON snapshot, whole-snapshot saves
  src/commands.rs       the IPC surface
```

## Conventions worth not relearning

- **`bindings.ts` is generated**, on every debug build, from the
  `#[specta::specta]` commands registered in `collect_commands!`. A command
  that isn't in that list simply doesn't exist on the frontend.
- **Stores own data; pages render it.** SvelteKit re-mounts a page on every
  navigation, so page-local fetched state is a bug — it refetches on every
  back-and-forth and loses scroll/filter state.
- **Control heights bind to `--density-target`**, never to a fixed `h-*`.
  That's what makes the comfortable/compact switch reach the whole UI.
- **Ask `breakpoint`, not `window.innerWidth`.** One definition of "this is
  wide enough for the rail".
- **The theme lives in `theme.css`.** Adding a colour means adding a token
  there and mapping it in `app.css`'s `@theme inline` — not a hex value in a
  component.

## Template updates

Tooling (justfile, git hooks, CI) comes from `template-rust`; the app scaffold
from `template-tauri`. They keep separate answers files:

```sh
copier update                                # tooling
copier update -a .copier-answers-tauri.yml   # scaffold
```
